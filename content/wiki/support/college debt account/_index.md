To ensure that only authenticated members can access certain College Debt resources, we deployed an account system powered using Microsoft 365.

## Claim your account

Every single member all have a Microsoft account provisioned for them. This is separate from the personal Microsoft account you may use for Minecraft or Windows. Reach out to an admin to get your temp password if this is your first time using the account or if you get locked out.

You're not required to claim your account

## Account security

For best security practice, we highly recommended that you save your password to a password manager and enable two-factor authentication using a TOTP authenticator app or via a security key. If possible, also use a randomly generated password if using a password manager.

## Privacy policy

We generally do not collect nor use any traceable data that comes from the usage of your account. Because Cloud Debt accounts are hosted by Microsoft, any legal language or big worded policy are bounded in part by [Microsoft Services Agreement](https://www.microsoft.com/en-us/servicesagreement), but we generally have more legal protections over our data as an enterprise organization.
